# prompts_pretsalemploi.md
# AI Compass — Prompts prêts à l'emploi pour les commerciaux DEF Ouest

---

## MODE D'EMPLOI

Ces prompts sont des points de départ. Toujours :
1. Remplacer les éléments entre [crochets] par tes vraies données
2. Relire et valider le résultat avant tout envoi
3. Ne jamais coller de données clients confidentielles (CDC, plans, coordonnées)

---

## CAS 01 — Compte rendu de visite

```
Rédige un compte rendu de visite client structuré à partir de ces notes :

Client : [nom ou type d'établissement, sans données identifiantes]
Date : [date]
Participants : [fonctions uniquement, pas de noms]
Contexte : [type de site, enjeux sécurité incendie]
Points abordés : [liste des sujets discutés]
Décisions prises : [ce qui a été acté]
Prochaines étapes : [actions à mener, délais]

Format souhaité : paragraphes courts, ton professionnel,
une section "Prochaines étapes" avec responsables et délais.
```

---

## CAS 02 — Offre commerciale et devis

```
Aide-moi à structurer une offre commerciale pour :

Type de client : [ERP / site industriel / bâtiment tertiaire]
Besoin identifié : [détection incendie / extinction / les deux]
Contexte réglementaire : [normes applicables si connues : APSAD R7, NF S 61-932...]
Points forts à mettre en avant : [certifications DEF, références similaires, SAV]
Contraintes client exprimées : [budget, délai, contrainte technique]

Rédige une introduction percutante et un plan d'offre en 5 parties.
Ne génère pas les chiffres — je les ajouterai moi-même.
```

---

## CAS 03 — Réponse à appel d'offres

```
Je dois répondre à un appel d'offres. Aide-moi à structurer le mémoire technique.

Objet du marché : [description générale]
Type d'établissement : [ERP catégorie X / site industriel / autre]
Exigences clés du cahier des charges : [liste les points critiques]
Nos atouts différenciants : [certifications, références, délais, SAV]
Contraintes identifiées : [points de vigilance ou difficultés]

Propose un plan de mémoire technique en 6 à 8 parties avec
une introduction valorisant notre positionnement.
Je rédigerai le contenu technique moi-même.
```

---

## CAS 04 — Argumentaire produit

```
Crée un argumentaire commercial pour présenter cette solution :

Produit / système : [nom ou type de système]
Contexte client : [type de site, problématique sécurité]
Objections fréquentes à traiter : [prix, complexité, délai, maintenance]
Normes et certifications à mentionner : [APSAD, CNPP, NF...]
Ton souhaité : [convaincant mais factuel, pas de survente]

Format : 3 arguments clés avec preuve à l'appui,
puis réponses aux 2-3 objections principales.
```

---

## CAS 05 — Email de relance

```
Rédige un email de relance commercial pour :

Contexte : [suite à une visite / après envoi d'offre / sans nouvelles depuis X semaines]
Dernier échange : [résumé en 1-2 phrases]
Objectif de la relance : [obtenir un rendez-vous / une décision / un retour sur l'offre]
Ton : [professionnel et direct, sans être insistant]

Longueur : 5-8 lignes maximum.
Terminer par une question ouverte pour faciliter la réponse.
Ne pas inclure de données client identifiantes.
```

---

## CAS 06 — Synthèse de réunion technique

```
Rédige une synthèse de réunion technique à partir de ces éléments :

Objet de la réunion : [sujet]
Participants : [fonctions uniquement]
Durée : [durée]
Points discutés : [liste]
Décisions actées : [liste]
Points en suspens : [liste]
Actions à mener : [qui fait quoi, pour quand]

Format : synthèse en prose courte + tableau des actions
avec colonnes : Action / Responsable / Échéance.
```

---

## CAS 07 — Présentation pour décideurs

```
Aide-moi à structurer une présentation PowerPoint pour :

Audience : [CODIR client / directeur technique / acheteur]
Objectif : [valider un projet / présenter une solution / conclure un contrat]
Message principal à faire passer : [en une phrase]
Contrainte de temps : [durée de la présentation]
Éléments disponibles : [chiffres, références, schémas techniques]

Propose un plan en 6-8 slides avec le message clé de chaque slide.
Je construirai les visuels moi-même.
```

---

## CAS 08 — Synthèse d'audit conformité

```
Aide-moi à structurer une synthèse d'audit pour :

Type de site : [ERP / site industriel — sans données identifiantes]
Normes vérifiées : [APSAD R7 / NF S 61-932 / autre]
Constats principaux : [points conformes et non-conformes — sans références
aux personnes ou données confidentielles du site]
Niveau de risque global : [faible / moyen / élevé]

Format : synthèse exécutive 1 page + tableau des écarts
avec colonnes : Constat / Norme / Niveau de risque / Action recommandée.

ATTENTION : Ne pas inclure d'informations permettant
d'identifier le site (adresse, nom, plan).
```

---

## CAS 09 — Plan d'action correctif

```
Génère un plan d'action correctif structuré à partir de ces constats :

Contexte : [suite à audit / incident / inspection — sans données sensibles]
Constats à traiter : [liste des non-conformités]
Contraintes : [budget approximatif / délai réglementaire / ressources disponibles]
Priorités : [ce qui est urgent vs ce qui peut attendre]

Format : tableau avec colonnes :
Action / Priorité (1-2-3) / Responsable (fonction) / Délai / Indicateur de réussite.
```

---

## CAS 10 — Rapport d'activité périodique

```
Aide-moi à rédiger mon rapport d'activité [mensuel / trimestriel] :

Période : [mois / trimestre]
Faits marquants : [liste des événements clés]
Chiffres clés : [CA, nombre d'offres, taux de transformation — chiffres réels
à saisir toi-même]
Difficultés rencontrées : [obstacles, retards, problèmes]
Objectifs période suivante : [priorités et engagements]

Format : synthèse narrative de 2-3 paragraphes +
tableau de synthèse des indicateurs.
Ne génère pas les chiffres — je les remplirai.
```

---

## RÈGLES D'OR (rappel)

- Toujours relire avant d'envoyer — l'IA peut se tromper
- Jamais de données client confidentielles dans le prompt
- Les chiffres engageants (prix, délais, garanties) : toujours saisis manuellement
- En cas de doute sur la conformité du contenu : demander au référent IA
